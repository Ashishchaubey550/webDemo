# Navkar Tools & Machineries — Heavy Industrial B2B Platform

Official B2B website and industrial product catalog for **Navkar Tools & Machineries** (Station Road, Raipur, Chhattisgarh).

## 🛠️ Built With
- **Framework**: Next.js 16 (App Router)
- **UI & Logic**: React 19, Vanilla CSS Custom Design System
- **Aesthetic**: German & Swiss Industrial Heavy Tooling & Precision Machinery Design
- **Integration**: 1-Click WhatsApp RFQ Generator & Commercial Quotation Basket

## 🚀 Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally
```bash
npm run dev -- --port 3000
```
Open [http://localhost:3000](http://localhost:3000) to view the live platform.

### Build for Production
```bash
npm run build
npm run start
```
